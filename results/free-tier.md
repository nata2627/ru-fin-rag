# Бесплатные хостинги: что проверено 21.10.2026

Что требуется сервису: один процесс python, 527 МБ памяти в лексическом режиме (замер на маке,
`scripts/measure_latency.py` плюс RSS процесса), 24 МБ корпуса и 14 МБ индекса на диске,
открытый порт HTTP, работа без вмешательства рук.

| Вариант | Память | Засыпание | Карта | Что проверено и чем |
|---|---|---|---|---|
| HuggingFace Spaces, CPU Basic | 16 ГБ, 2 vCPU, 50 ГБ диска | засыпает на бесплатном железе | не нужна | документация Hub, раздел Spaces Overview: «Gradio and Docker Spaces run on compute and require a paid plan to create: PRO for personal accounts». Бесплатны только статические Spaces, плюс до двух Gradio Space на ZeroGPU для личных аккаунтов |
| Render, free web service | 512 МБ, общий CPU | через 15 минут без трафика, пробуждение около минуты | не нужна | документация Render, раздел Free: 750 часов инстанса в месяц на воркспейс, трафик 5 ГБ в месяц |
| Koyeb, free | 512 МБ, 1 vCPU общий | масштабируется в ноль через час | нужна с февраля 2026, только для проверки | обзоры бесплатных тарифов за 2026 год |

| GitHub Pages | статика, сервера нет | не засыпает | не нужна | подходит дашборду, не подходит API |

## Что из этого следует

Постановка (раздел 6а) называла HuggingFace Spaces на CPU основным ориентиром для сервиса.
На 21.10.2026 это больше не бесплатно для личного аккаунта: Docker и Gradio Space требуют
тарифа PRO. Это расхождение с постановкой, и оно идет на гейт G2.

Остается два пути. Первый: Render на бесплатном тарифе, 512 МБ памяти. Сервис в нынешнем виде
занимает 527 МБ и туда не влезает, значит нужна работа над памятью. Второй: HuggingFace PRO,
9 долларов в месяц, что противоречит требованию «без ее денег» (TASK, раздел 6а).

Засыпание через 15 минут это не поломка для демо, которое открывает работодатель: первый
запрос ждет около минуты, дальше сервис отвечает. Но это надо написать в README рядом со
ссылкой, а не прятать, и держать `/health` дешевым, чтобы пробуждение не стоило пятисот
миллисекунд на чтение корпуса.
