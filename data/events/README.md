# Журнал запросов сервиса

Здесь лежат файлы `queries-ГГГГ-ММ-ДД.jsonl`: одна строка JSON на событие, сутки по UTC. Пишет
их сервис (`src/rufinrag/events.py`), а в репозиторий переносит ночной прогон
(`scripts/drain_events.py`), потому что диск бесплатного хостинга эфемерный.

В строке есть текст запроса, который пользователь сам отправил в открытый сервис, выдача и
технические поля: версии корпуса и связки, задержки по ступеням, отказ или ответ. Заголовков
запроса, адреса, куки и идентификатора сессии в ней нет. Оценка пользователя приходит отдельным
событием с тем же `request_id`.

Файл первых суток появляется здесь после первой выгрузки с хостинга. Как по этим файлам
считается витрина, описано в README репозитория, раздел «Журнал запросов и витрина».
